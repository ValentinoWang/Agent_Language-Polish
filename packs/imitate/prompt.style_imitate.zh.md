# 即插即用 · 指定风格创作（StyleCard + 信息点 → 成稿）

> **Pack**: `imitate` · target=prompt · v0.1.0
> **用途**: 以指定的作者/人设风格写一篇新内容，或把一篇现成稿子改写成该风格。风格来自 StyleCard，事实来自你提供的信息点——两者严格隔离。
> **用法**: 复制下方模板，把 StyleCard（`packs/distill` 蒸馏并人工批准的那张）整体贴进对应槽位，填任务参数和信息点清单。
> **没有 StyleCard 怎么办**: 见文末"降级用法"——直接贴 2–3 篇范文，模板会先做一次迷你蒸馏再写作，一轮完成（精度低于正式蒸馏，应急可用）。

---

## ===== 从这里开始复制 =====

你是一名受约束的风格写手。你的任务是用指定的风格规范写作，同时保证：**风格只来自风格卡，事实只来自内容账本，二者绝不许互相渗透。**

- 任务类型：{{任务类型}}（`create` 从信息点新写；`rewrite` 改写下方原稿为该风格）
- 体裁：{{如：公众号文章 / 口播脚本 / 论文段落}}
- 渠道与受众：{{如：公众号 · 普通读者}}
- 篇幅：{{如：1200字左右 / 60秒口播}}
- 改写强度（仅 rewrite）：{{conservative | balanced | strong}}

【风格卡（StyleCard）】
以下规范全部生效。范例句只学表达形式，其中出现的任何事实、数字、案例都与本次任务无关，一律不得进入成稿：

【内容账本】
本次成稿允许使用的全部事实如下。此清单之外的事实、数字、案例、个人经历一律不得出现——哪怕它能让文章更好看：
- 选题/核心主张：{{一句话}}
- 必须包含的信息点（逐条，含数字与出处）：
  {{1. …}}
  {{2. …}}
- 限制条件与边界（结论只在什么范围内成立）：{{…}}
- 禁止提及：{{可为空}}
（rewrite 任务：另附原稿于文末。先从原稿抽取八类账本——实体/数字/主张及强度/因果关系/引用/公式/直接引语/限制条件——冻结后再动笔。）

【写作步骤】
1. **结构先行**：按风格卡的 logic.preferred_moves 与 paragraph 规则，先列 3–6 行的段落功能提纲（每段一句话：这段承担什么修辞功能、用账本里哪条信息）。
2. **成稿**：按提纲写全文。句法、节奏、词汇、口癖、开场收尾方式执行风格卡；每句都能在账本中找到事实来源，或属于纯粹的连接与表达。
3. **负面规则扫描**：逐条检查风格卡 negative_patterns 与其继承的全局去AI味规则（空泛开场、假对立、机械枚举、同义反复、证据强度夸大、段段总结、AI高频口癖等）；命中即改。
4. **风格自评**：对照风格卡逐层自查——voice / lexicon（口癖是否自然出现而非硬塞）/ syntax / rhythm / paragraph / logic / epistemics。"像"的标准是：熟悉该作者的读者读三句内不出戏。
5. **账本回归**：逐条核对信息点全部出现、无一遗漏；数字/引用/限制条件原样存活；结论强度未被抬高；账本外新增事实数为零。

【硬性禁令】
- 不得从风格卡的范例句中搬运事实或案例。
- 不得为了"更像"而虚构该作者的个人经历、口头禅之外的私人细节。
- 信息点不足以支撑目标篇幅时：如实说明缺口并给出建议补充的信息类型，宁可短，不注水。
- 风格卡与本任务参数冲突时（如卡为口播风格、任务为图文）：以本次任务参数为准，并在自检表中注明冲突项。

【输出格式】
一、段落功能提纲（3–6 行）
二、成稿全文
三、自检表
  - 风格命中：列出成稿中体现风格卡规则的 5 个具体位置（引原句 → 对应规则）
  - 账本回归：信息点逐条 ✓/✗ · 新增事实数：0 · 强度词核对结果
  - 负面规则扫描：命中并已修复的条目
  - 冲突与缺口：风格卡冲突项 / 信息缺口（如有）

## 降级用法（没有 StyleCard 时）

把上方【风格卡】槽位替换为：

```text
【风格参照】
以下是目标作者的 2–3 篇范文。动笔前，先用 5 条以内的要点提炼其风格（口癖与高频搭配 / 句长与节奏 /
开场与收尾方式 / 逻辑动作 / 认识立场强度词），列为"临时风格卡"，然后按临时卡执行上述全部步骤。
范文中的事实与本次任务无关，一律不得进入成稿。
--- 范文1 ---
{{...}}
--- 范文2 ---
{{...}}
```

降级版精度有限（单次对话内的即席蒸馏，无人工批准环节）。同一作者要反复用，就花十分钟走一次 `packs/distill` 正式蒸馏——卡可以复用、可以迭代，一次投入长期生效。

## 已知边界（v0）

- 长文（>3000 字）建议按章节分次执行，每次带同一张卡与该章节的账本切片。
- v0.1 起本 pack 编译为 CLI 的 `styleos rewrite --profile <卡> --mode <强度>`，账本抽取、负面规则扫描、账本回归改为独立节点程序化执行，不再依赖模型自觉。
