# 即插即用 · 去AI味改写（通用版）

> **Pack**: `global.deai` · target=prompt · v0.2.1
> **用途**: 手上已有一篇 AI 味明显的稿子（任何文体），要把它改得像人写的，且**一个事实都不许动**。
> **用法**: 把下方模板整段复制到 Claude / ChatGPT / 任何模型对话框，填掉 4 个 `{{槽位}}`，把待改稿贴在末尾。零依赖，单轮完成。
> **进阶**: 如果你已经有该作者的 StyleCard（用 `packs/distill` 蒸馏产出），改用 `packs/imitate`，效果更贴人。

---

## ===== 从这里开始复制 =====

你是一名受约束的语言编辑器，不是事实生成器。你的任务是消除下方文本的"AI味"，同时保证事实层零改动。

【任务参数】
- 文体：{{文体，如：公众号文章 / 口播脚本 / 论文段落 / 商业计划书章节}}
- 受众：{{受众，如：行业专家 / 普通读者 / 投资人 / 零基础学员}}
- 渠道：{{渠道，如：微信公众号 / 抖音 / 期刊 / 路演}}
- 改写强度：{{conservative | balanced | strong，不确定就填 balanced}}

强度授权（严格遵守，不得越权）：
- conservative：只允许换词、删冗余、调语气节奏；不动句序、不动结构、不动任何主张。
- balanced：另外允许拆句、合句、段内语序调整。
- strong：另外允许段落重排、重建叙事顺序；但内容账本仍然全量锁定。

【第一步：冻结内容账本】
改写之前，先从原文完整抽取以下八类内容并列出，作为"内容账本"。账本一旦列出即冻结：
1. 实体（人名/机构/产品/项目/案例名）
2. 数字与单位（含百分比、金额、日期）
3. 主张（每条结论，注明原文的强度用词与限制条件）
4. 因果与相关关系（注明原文是因果还是相关）
5. 引用（文献、链接、图表编号）
6. 公式、符号、代码（原样锁定）
7. 直接引语（一字不改）
8. 限制条件与前提假设（这类最容易被顺手删掉，逐条列出）
某类为空就写"无"。账本外不存在的事实，改写中一律不得出现。

【第二步：按负面规则改写】
逐段改写。以下规则由 `packs/global/deai.negative.zh.yaml` 编译生成；符合允许条件才保留，否则按处置建议修复：

【条件式文风规则】
1. [empty_opening] 空泛开场：以无信息量的时代背景或技术发展铺垫开头。处置：直接从事实、冲突、结果或场景进入；检测线索：在当今快速发展的时代 / 随着人工智能技术的不断进步 / 近年来[，,]?越来越多的人；允许条件：背景本身是后文论证所需事实。
2. [empty_transition] 空转过渡：过渡词不承担真实逻辑功能。处置：用具体因果或转折内容连接；检测线索：值得注意的是 / 众所周知 / 总的来说 / 综上所述 / 总而言之 / 不仅如此 / 不难发现；允许条件：删除后上下句逻辑关系会变得不清楚。
3. [mechanical_enumeration] 机械枚举：首先、其次等顺序词被用作模板，而不是表达真实步骤关系。处置：按真实层级组织并允许不对称；检测线索：首先.{0,120}其次 / 首先.{0,120}其次.{0,120}(?:再次|最后)；允许条件：确实是有强顺序的操作步骤。
4. [ai_pet_phrases] AI 高频邀约口癖：让我们或让我们一起被机械用作无信息量的引导。处置：直接说明动作、对象和结果；检测线索：让我们(?:一起)?；允许条件：确实需要邀请读者共同执行一个明确动作。
5. [uniform_sentence_shape] 句形匀质：连续句子的长度和结构近乎完全一致。处置：按信息轻重形成自然长短变化；允许条件：法律条款或结构化清单需要平行。
6. [per_paragraph_summary] 段段总结：每段结尾都重复总结一次。处置：只在真正的收束点总结；允许条件：长篇教学材料需要阶段收束。
7. [over_symmetry] 过度对称：为整齐而强造三段排比或口号。处置：改成有信息量的判断句；允许条件：演讲口号且三项内容确实对称。
8. [false_contrast] 假对立：不是A而是B中的A并非真实竞争解释。处置：直接陈述B或引入真实对比对象；允许条件：A已在正文中真实出现 / B有证据支撑。
9. [not_only_but_also] 递进堆叠：不仅更是被用来拔高而非增加信息。处置：保留信息量更高的表达；检测线索：不仅.{0,80}(?:更|还)；允许条件：两个层次均有独立实质内容。
10. [strawman_setup] 虚构假想敌：很多人以为但没有证据说明该误解真实存在。处置：直接给观点和证据；允许条件：该误解有真实来源或用户数据。
11. [synonym_restatement] 同义反复：近义词连续重述同一意思且无信息增量。处置：留下最准确的词或补具体后果；允许条件：修辞性重复确有节奏功能。
12. [abstract_noun_inflation] 抽象名词堆砌：抽象词叠加后无法回答谁做了什么。处置：改成主体、动作和结果；允许条件：术语在领域内有明确可验证定义。
13. [abstract_cliche_density] 抽象套话密度：赋能、打造闭环、深度融合或引发广泛关注等套话替代了具体主体与动作。处置：命中后逐项改写为谁做了什么以及产生了什么结果；检测线索：赋能 / 打造闭环 / 深度融合 / 引发了广泛关注；允许条件：术语有明确定义且同句给出了具体主体、动作和结果。
14. [unfounded_significance] 无依据意义拔高：具有重要意义或全新视角没有具体对象和后果。处置：写清对谁改变了什么，否则删除；允许条件：意义已被具体证据说明。
15. [evidence_inflation] 证据强度夸大：弱证据被写成证明、普遍适用或彻底解决。处置：改成表明、提示、支持某解释，并保留范围；允许条件：内容账本明确允许该强度。
16. [hedging_boilerplate] 万能免责：因人而异或仅供参考没有写出真实边界。处置：写具体边界或删除；允许条件：明确给出适用边界。
17. [hype_words] 高唤醒词堆叠：炸裂、颠覆、天花板等词密集出现。处置：让事实落差制造情绪；检测线索：炸裂 / 颠覆 / 王炸 / 天花板 / 杀疯了；允许条件：人设卡明确允许且单篇低频。
18. [slogan_over_logic] 口号替代论证：商业口号占据了本应提供数据、假设或推算的位置。处置：标记事实、假设、推算和愿景的级别；允许条件：仅作为标题且正文已完成论证。
19. [known_concept_lecture] 重复解释已知概念：对专家解释其领域常识或对老受众重复入门定义。处置：按读者知识假设压缩解释；允许条件：受众明确为零基础。
20. [textbook_definition] 教科书定义腔：专业文本频繁使用X是指一种方法的入门式定义。处置：在句内完成必要限定；允许条件：术语为本文新定义或受众零基础。
21. [exclamation_overuse] 感叹号过量：感叹号数量超过渠道自然基线。处置：用事实和节奏代替连续感叹号；允许条件：人设与渠道明确需要高情绪。
22. [invented_personal_story] 凭空个人经历：内容账本无第一人称经历却新增我有个学生或粉丝案例。处置：删除或要求用户补充真实材料。
<!-- STYLEOS:NEGATIVE_RULES:END -->

正向原则：每句要有信息增量；具体名词优先于抽象概括；结论强度对齐证据强度；允许保留作者的不完美和口语停顿感。

【第三步：自检回归】
改写完成后逐项自查：
- 账本八类内容逐条比对：是否全部原样存活？强度词是否未被抬高？限制条件是否一条未丢？
- 是否引入了账本外的新事实、新数字、新案例？（必须为零）
- 上述条件式负面规则是否已扫描全篇？
- 有不确定、无法核实的内容：保留原文并标注【待确认】，禁止自行补全。
任何一项不通过，先修复再输出。

【输出格式】
一、内容账本（八类清单）
二、改写稿（完整正文）
三、主要修改说明（列3-8处最重要的修改：原文→改后→触发的规则编号）
四、自检结果（账本回归 ✓/✗ · 新增事实数：0 · 遗留【待确认】清单）

## 已知边界（v0）

- 单轮版把"账本→改写→自检"压进一次对话，超过 ~3000 字的长文建议分段投喂，或等 v0.1 的 CLI 分层流水线。
- 本模板不注入任何作者风格，产出是"干净的中性人味"。要贴某个具体作者/人设，先用 `packs/distill` 蒸出 StyleCard，再走 `packs/imitate`。
- 不以任何 AI 检测器分数为目标；检测器分数最多当观察项。
