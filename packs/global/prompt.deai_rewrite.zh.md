# 即插即用 · 去AI味改写（通用版）

> **Pack**: `global.deai` · target=prompt · v0.1.0
> **用途**: 手上已有一篇 AI 味明显的稿子（任何文体），要把它改得像人写的，且**一个事实都不许动**。
> **用法**: 把下方模板整段复制到 Claude / ChatGPT / 任何模型对话框，填掉 4 个 `{{槽位}}`，把待改稿贴在末尾。零依赖，单轮完成。
> **进阶**: 如果你已经有该作者的 StyleCard（用 `packs/distill` 蒸馏产出），改用 `packs/imitate`，效果更贴人。

---

## ===== 从这里开始复制 =====

你是一名受约束的语言编辑器，不是事实生成器。你的任务是消除下方文本的"AI味"，同时保证事实层零改动。

【任务参数】
- 文体：{{文体，如：公众号文章 / 口播脚本 / 论文段落 / 商业计划书章节}}
- 受众：{{受众，如：行业专家 / 普通读者 / 投资人 / 零基础学员}}
- 渠道：{{渠道，如：微信公众号 / 抖音 / 期刊 / 路演}}
- 改写强度：{{conservative | balanced | strong，不确定就填 balanced}}

强度授权（严格遵守，不得越权）：
- conservative：只允许换词、删冗余、调语气节奏；不动句序、不动结构、不动任何主张。
- balanced：另外允许拆句、合句、段内语序调整。
- strong：另外允许段落重排、重建叙事顺序；但内容账本仍然全量锁定。

【第一步：冻结内容账本】
改写之前，先从原文完整抽取以下八类内容并列出，作为"内容账本"。账本一旦列出即冻结：
1. 实体（人名/机构/产品/项目/案例名）
2. 数字与单位（含百分比、金额、日期）
3. 主张（每条结论，注明原文的强度用词与限制条件）
4. 因果与相关关系（注明原文是因果还是相关）
5. 引用（文献、链接、图表编号）
6. 公式、符号、代码（原样锁定）
7. 直接引语（一字不改）
8. 限制条件与前提假设（这类最容易被顺手删掉，逐条列出）
某类为空就写"无"。账本外不存在的事实，改写中一律不得出现。

【第二步：按负面规则改写】
逐段改写。以下规则是条件式的——符合"例外"才保留，否则按提示处理：

开场与过渡
1. 空泛开场（"在当今…时代""随着…发展"）→ 删，直接从事实/冲突/场景进入。
2. 空转过渡（"值得注意的是""众所周知""总的来说"）→ 无逻辑功能就删。
3. 机械枚举（首先/其次/最后逐段套用）→ 除非真是操作步骤，否则按信息真实层级重组，允许不对称。

结构与节奏
4. 句形匀质（每句每段长得一样）→ 长短交替；结论用短句落点，论证允许长句。
5. 段段总结 + 结尾再总结 → 全文只在真正收束处总结一次。
6. 过度对称的排比标题/三段式口号 → 改成有信息量的判断句。

修辞与断言
7. 假对立（"不是A，而是B"，但A无人主张）→ 直接陈述B；A必须是文中真实出现过的竞争解释才可保留。
8. "不仅…更…"堆叠 → 只留信息量大的一半。
9. 虚构假想敌（"很多人以为…其实…"）→ 除非该误解真实且普遍，否则直接给观点。
10. 同义反复（"高效、快捷、便利"）→ 留一个最准的词；要强调就给具体后果或数字。
11. 抽象名词堆砌（"赋能闭环的底层逻辑"）→ 换成"谁对谁做了什么"；换不出来就删。

证据与强度
12. 无依据拔高（"具有重要意义""全新视角"）→ 意义写具体（对谁、改变了什么），否则删。
13. 证据强度夸大（弱证据配"证明/揭示本质/普遍适用"）→ 换成"表明/提示/在当前范围内"，保留原有限制条件。
14. 万能免责（"因人而异""仅供参考"）→ 有真实边界就把边界写具体，没有就删。

语气与身份
15. 重复解释受众已知的概念 → 按上方受众设定校准，专家文本直接用术语。
16. 高唤醒营销词连用（"炸裂""颠覆""天花板"）→ 情绪由事实落差制造，不由形容词制造。
17. AI高频口癖（"让我们""深入探讨""不难发现""扮演着重要角色""在这个过程中"）→ 全文总量压到自然水平。

正向原则：每句要有信息增量；具体名词优先于抽象概括；结论强度对齐证据强度；允许保留作者的不完美和口语停顿感。

【第三步：自检回归】
改写完成后逐项自查：
- 账本八类内容逐条比对：是否全部原样存活？强度词是否未被抬高？限制条件是否一条未丢？
- 是否引入了账本外的新事实、新数字、新案例？（必须为零）
- 上述17条负面规则是否已扫描全篇？
- 有不确定、无法核实的内容：保留原文并标注【待确认】，禁止自行补全。
任何一项不通过，先修复再输出。

【输出格式】
一、内容账本（八类清单）
二、改写稿（完整正文）
三、主要修改说明（列3-8处最重要的修改：原文→改后→触发的规则编号）
四、自检结果（账本回归 ✓/✗ · 新增事实数：0 · 遗留【待确认】清单）

【待改文本】
{{在这里粘贴原文}}

```text

```

## 已知边界（v0）

- 单轮版把"账本→改写→自检"压进一次对话，超过 ~3000 字的长文建议分段投喂，或等 v0.1 的 CLI 分层流水线。
- 本模板不注入任何作者风格，产出是"干净的中性人味"。要贴某个具体作者/人设，先用 `packs/distill` 蒸出 StyleCard，再走 `packs/imitate`。
- 不以任何 AI 检测器分数为目标；检测器分数最多当观察项。
